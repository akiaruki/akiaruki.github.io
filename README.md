# Aki public websites

This repository is the maintained source for the short public website addresses. Edit these pages directly; the former aki-portfolio-pages mirror workflow has been retired.

- `aki-studio/` — Studio, including support and privacy pages
- `aki-camera/` — Camera
- `aki-gazette/` — Gazette
- `aki-moments/` — Moments
- `portfolio/` — portfolio

GitHub Pages publishes the `main` branch. Keep canonical URLs on `https://akiaruki.github.io/`, and update `sitemap.xml` when adding or removing a listed public page. Old aki-portfolio-pages HTML addresses redirect here.
